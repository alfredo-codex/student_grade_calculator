## Description
This is a simple Python program that calculates students' grades based on their scores.

## Features
- Accepts students' scores.
- Calculates the average score.
- Determines the student's grade.
- Displays the result.

## Technologies Used
- Python 3

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

python grade_calculator.py
